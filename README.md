# AthletiQ

A comprehensive tournament management system for schools and sports organizations.

## Quick Start

### Backend
```bash
cd athletiq-backend
npm install
npm start
```

### Frontend
```bash
cd athletiq-frontend/athletiq-web
npm install
npm start
```
